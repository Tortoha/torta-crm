# Targets & Alerts

Two related tools for staying on top of the store without watching it all day. **Targets** are goals you commit to; **Alerts** ping you when a metric crosses a line. Both live in the project's Overview section.

## Targets

Set a goal for a metric and watch progress toward it.

**What you can target:** revenue, orders, new customers, conversion rate, average order value, return rate, bookings, average rating — and **custom events** you fire from the storefront (`client.track.goal`, see [Tracking](/docs/tracking)). Each target runs over a period (1 day to 1 year, or all-time).

**What you can do:**

- **Create a target** — choose the metric, the value to hit, and the period.
- **Track progress** — grid view shows a big percentage; list view shows compact progress bars. Colors signal at a glance: achieved, on-track, or behind.
- **Activate / deactivate** with a quick toggle, no need to open it.
- **Search, sort and filter** by status (active / inactive / achieved).

## Alerts

Get notified the moment something needs your attention.

**Alert types:**

- **Revenue drop** — revenue falls below a threshold.
- **Low stock** — a product dips under a stock threshold.
- **Daily summary** — a once-a-day recap.
- **New order** — fires on every incoming order.

Some types take a numeric threshold; alerts can be delivered to an email.

**What you can do:**

- **Create / edit** an alert: pick a type, set its threshold or email, toggle it active.
- **Mute or activate** without deleting.
- **Search, sort and filter** (by type, recent activity, active/muted) and switch grid/list views.
- **Recent fires** — a read-only log of when each alert last triggered.

## Targets vs Alerts

Think of it this way: a **target** tracks how close you are to a goal over time; an **alert** is a one-off ping when a number crosses a line *right now*. They pair well — set a revenue target for the quarter, and a revenue-drop alert so you hear about a bad week immediately. Both read the same numbers you see in [Analytics](/docs/analytics).
