# Команда и роли

**Организация → Команда** — здесь вы управляете тем, у кого есть доступ к CRM и что им разрешено делать. Открыть может только владелец организации.

## Участники

Вкладка **Участники** показывает всех в команде — имя, email и сводку доступа по проектам.

- **Добавить участника** — открывает многоразовую ссылку-приглашение для организации. Поделитесь ей; кто откроет — присоединится как участник. Ссылку можно в любой момент сбросить, чтобы старая перестала работать.
- **Управление доступом** (меню ⋮ у участника) — назначьте участнику **роль** в каждом проекте отдельно. Один человек может быть менеджером в одном магазине и не иметь доступа к другому.
- **Удалить** — отзывает доступ участника ко всей организации.

У владельца всегда полный доступ, и его нельзя удалить.

## Роли

Вкладка **Роли** — где вы определяете, что роль может делать. Роль — это **матрица прав** по страницам консоли, с тремя уровнями для каждой:

| Уровень | Значение |
|---------|----------|
| **None** | страница скрыта |
| **View** | можно открыть и читать |
| **Manage** | можно редактировать / выполнять действия |

- Готовые роли уже есть; свои создаются кнопкой **Новая роль**.
- Редактор группирует страницы (Товары, Продажи, Бронирование, Вовлечение, Настройка…) и имеет массовые кнопки *Снять всё / Всё View / Всё Manage*.
- Изменения сохраняются автоматически — кнопки «Сохранить» нет.

## Как работает доступ

Доступ проверяется на бэкенде, а не просто прячется в интерфейсе. Участник видит только те страницы, которые даёт его роль в конкретном проекте, и уведомления подчиняются тому же правилу — вы не получите оповещения по проекту (или странице вроде Чата), к которым у вас нет доступа.

См. также: [Организации и проекты](/docs/organizations-projects).
