# С чего начать

Добро пожаловать в **Torta CRM** — консоль, где вы управляете магазинами, клиентами, заказами и API, на котором работает ваша витрина.

## Общая картина

Torta устроена в три уровня:

1. **Организация** — аккаунт верхнего уровня. Компания или бренд.
2. **Проект** — один магазин / филиал внутри организации. У каждого проекта свои товары, заказы, клиенты и API-ключи.
3. **Консоль** — набор страниц одного проекта (Товары, Заказы, Аналитика, Аутентификация и т.д.).

> В одной организации может быть много проектов. Например, бренд одежды с магазинами в разных странах — это одна организация и по одному проекту на страну.

## Первые шаги

1. Создайте **организацию** на дашборде.
2. Внутри неё создайте **проект** и укажите URL своей витрины.
3. Откройте проект — вы попадёте на **Обзор проекта**.
4. Возьмите **API-ключи** из кнопки *Copy Keys* (вверху обзора) и подключите витрину через [torta-js](/docs/quickstart).

## Три ключа

У каждого проекта три ключа, у каждого своя задача:

| Ключ | Где находится | Для чего |
|------|---------------|----------|
| **Публичный ключ** | в URL запроса | определяет магазин |
| **Публикуемый ключ** | заголовок `X-Publishable-Key` (безопасен в браузере) | обычные запросы витрины (товары, корзина, вход) |
| **Секретный ключ** | только на сервере — никогда в браузере | доверенные серверные вызовы (например, приём клиентов) |

Публичный и публикуемый ключи рассчитаны на то, чтобы лежать в JavaScript витрины. А **секретный ключ должен оставаться на вашем сервере** — кто им владеет, тот может писать данные в вашу CRM.
