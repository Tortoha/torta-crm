# Настройки

**Проект → Настройки** содержит общие для проекта параметры, которые влияют на работу всей остальной консоли. Всё сохраняется по мере изменения.

## Общие

- **Часовой пояс** — выберите из пресетов или задайте свой. Используется везде, где показываются даты и время, и задаёт время слотов бронирования.
- **Валюта** — символ и формат для всех цен в консоли. Прошлые заказы сохраняют валюту, в которой были оформлены, поэтому исторические отчёты остаются точными при смене валюты.

## Склад

- **Списание партий** — FIFO или LIFO, используется когда остатки ведутся [партиями](/docs/products).
- **Отображение цен** — переключатели вроде скрытия цен или показа маржи в каталоге.

## Штрихкоды по умолчанию

Выберите, что кодируют ваши штрихкоды (SKU, ID товара, партию, цену).

## Уровень проекта vs аккаунта

Эта страница — на уровне **проекта**. Личные настройки (язык интерфейса, тема) находятся в **настройках аккаунта**, а параметры всей организации (оплата, общие клиенты, команда) — на уровне [организации](/docs/organizations-projects).
