# Организации и проекты

## Организации

**Организация** — это ваш аккаунт верхнего уровня. В ней живут проекты, команда, настройки оплаты и общие для организации параметры.

Откройте **Организация → Настройки**, чтобы переименовать её, задать валюту для аналитики уровня организации или выбрать режим общих клиентов (ниже).

## Проекты

**Проект** — это один магазин (или филиал). У него свои:

- товары, заказы, возвраты, клиенты
- аналитика, алерты, цели
- провайдеры входа (email, Google, телефон, …)
- API-ключи

Переключаться между проектами можно через переключатель в «хлебных крошках» вверху страницы.

## Команда и роли

Приглашайте сотрудников в **Организация → Команда**. У каждого участника своя **роль** на проект, и роль определяет, какие страницы он видит и может редактировать (Товары, Заказы, Чат и т.д.). У владельца организации всегда полный доступ.

## Общие клиенты (несколько филиалов)

В **Организация → Настройки → Клиенты** вы выбираете, как ведут себя аккаунты клиентов между проектами организации:

- **Общие для организации** *(по умолчанию)* — один аккаунт клиента работает во всех филиалах. Клиент регистрируется один раз и узнаётся в любом магазине. Настройки входа тоже общие для филиалов. Подходит для сетей и брендов с филиалами.
- **По проекту** — у каждого магазина своя изолированная база клиентов. Клиент одного филиала не является клиентом другого.

Переключение на режим *По проекту* попросит ввести имя организации для подтверждения — потому что после расхождения филиалов объединить их обратно получится не всегда.
