# Приём клиентов (со своего сервера)

Если у вас **своя** аутентификация и вы просто хотите, чтобы клиенты появлялись в CRM, — присылайте их со своего бэкенда. Переносить вход к нам не нужно.

## Используйте секретный ключ

Это **серверный** вызов. Он использует **секретный ключ** проекта (`sk_…`) в заголовке `X-Secret-Key`. Никогда не кладите секретный ключ в код браузера — он должен жить на вашем сервере.

```js
import { createClient } from 'torta-js';

// secretKey передаётся 3-м аргументом — только на сервере
const client = createClient(API_URL, API_PK, { secretKey: process.env.TORTA_SECRET_KEY });

await client.customers.save({
  email: "ann@example.com",
  name: "Анна",
  surname: "Ли",
  phone: "+10000000000",
  birthdate: "1995-03-01",   // ГГГГ-ММ-ДД
  address: "ул. Маркет, 1",
  metadata: { tier: "gold" } // любые свои поля
});
```

Или вызовите эндпоинт напрямую:

```bash
curl -X POST "https://api.example.com/PUBLIC_KEY/customers" \
  -H "Content-Type: application/json" \
  -H "X-Secret-Key: sk_YOUR_SECRET_KEY" \
  -d '{"email":"ann@example.com","name":"Анна","surname":"Ли","metadata":{"tier":"gold"}}'
```

## Поведение

- **Upsert по email** (затем по телефону): повторная отправка того же клиента **обновляет** запись, а не создаёт дубль.
- Пустые поля не затирают существующие значения, а `metadata` **сливается**, а не заменяется.
- Такие клиенты сохраняются как **внешние** (без пароля и входа здесь) — и видны на странице «Клиенты» как обычные.
- Нужен хотя бы один из `email` или `phone`.

## Поля

| Поле | Примечание |
|------|------------|
| `email` / `phone` | идентификатор — нужен хотя бы один |
| `name`, `surname` | имя / фамилия |
| `birthdate` | дата в формате `ГГГГ-ММ-ДД` |
| `address` | адрес одной строкой |
| `metadata` | произвольный объект для ваших полей |
