# Платежи

Подключите платёжного провайдера, чтобы клиенты платили при оформлении заказа. **Torta не касается денег** — платежи идут напрямую на *ваш* счёт провайдера, что освобождает вас от PCI-комплаенса и лицензий на работу с деньгами.

Три варианта, намеренно простые:

| Вариант | Что делает | Куда идут деньги |
|---|---|---|
| **Stripe** | Реальная онлайн-оплата картой на вашей витрине | Прямо на ваш счёт Stripe |
| **Manual** | Только запись — наличные, перевод, оплата при получении | Собираете сами, вне платформы |
| **Other** | Только запись — любой шлюз, который мы не интегрируем (Kaspi, своя ссылка…) | Собираете сами; фиксируете референс |

## Почему только Stripe?

Мы делаем **одну** глубокую интеграцию вместо дюжины поверхностных. У каждого шлюза (PayPal, Adyen, Mollie…) своя механика оплаты — где-то редирект, где-то хостед-виджет, где-то нужен каталог. Полу-готовые интеграции хуже их отсутствия: выглядят рабочими, но ломаются в мелочах.

Stripe — самый «API-native» процессинг: он отдаёт бэкенду payment intent, а форму карты вы рисуете как хотите. Поэтому Stripe получает полную инлайн-интеграцию, а **всё остальное идёт через Manual / Other** — любой провайдер, просто фиксируете оплату. Одна интеграция, сделанная как надо, плюс универсальный fallback.

## Подключить Stripe

1. Заведите бесплатный [аккаунт Stripe](https://stripe.com). Для старта в **test mode** не нужны ни карта, ни компания.
2. В Stripe → **Developers → API keys** скопируйте **Publishable key** (`pk_test_…`) и **Secret key** (`sk_test_…`).
3. В Torta откройте **Организация → Payments → Stripe**, вставьте оба ключа, нажмите **Save**.
4. Нажмите **Test** — Torta пингует Stripe и проверяет ключи. При успехе строка станет **Connected**.

После подключения витрина собирает карту инлайн (Stripe Elements), а заказ создаётся **только после подтверждения оплаты Stripe**. Переключитесь на боевые ключи (`pk_live_…` / `sk_live_…`), когда будете готовы принимать реальные деньги.

> **Тестовая карта:** `4242 4242 4242 4242`, любая будущая дата, любой CVC. В test mode реальные деньги не двигаются.

## Manual и Other

Выберите **Manual** для наличных / перевода / оплаты при получении, или **Other** для любого неинтегрированного шлюза. Заказ записывается со статусом оплаты **`manual`** — он **не** помечается оплаченным. Деньги вы собираете сами и подтверждаете до отгрузки. Возвраты в этих режимах — только учётные (деньги возвращаете отдельно).

## Безопасность в одну строку

Карта клиента обрабатывается **напрямую Stripe** — она не доходит до наших серверов, так что PCI-нагрузка не на вас. Деньги попадают на **ваш** счёт, не на наш. Как именно это обеспечено на уровне API — см. [API: Платежи](/docs/payments-api).
