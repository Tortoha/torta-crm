# Авторизация

**Проект → Авторизация** управляет тем, как покупатели входят на вашу витрину, и URL-адресами магазина. Две вкладки: **Провайдеры входа** и **Настройка URL.**

## Провайдеры входа

Список всех способов входа. У каждой строки бейдж Включён/Выключен; клик открывает окно настройки.

### Email и Телефон (одноразовые коды)

- **Email** — вход без пароля по коду из письма. В панели задаются ваш домен отправки, имя и адрес отправителя, с живым предпросмотром. При сохранении Torta генерирует DNS-записи (DKIM, SPF, DMARC), показанные в таблице с кнопками копирования и кнопкой **Check DNS**. Бейдж показывает **Verified**, только когда проходят все три записи — без DMARC особенно Gmail/Outlook могут отправить письма в спам. («DNS может распространяться не сразу».)
- **Телефон** — вход по SMS-коду. Выберите **SMS-провайдера** из длинного списка по регионам (Twilio, Vonage, AWS SNS, Plivo; SMSC.ru / SMS.ru; Mobizon.kz; Eskiz; MSG91; WhatsApp Business; Telegram Gateway и другие) и заполните его данные. Также можно задать срок жизни кода, длину кода, шаблон SMS и **тестовые номера**, чтобы проверять без реальной отправки.

### Google и другие OAuth

- У **Google** своя панель: включите, вставьте **Client ID** и **Client Secret** и скопируйте **Redirect URI** в Google Cloud Console.
- Ещё **~17 OAuth-провайдеров** используют общую панель — GitHub, Discord, Facebook, GitLab, Bitbucket, LinkedIn, Twitch, Spotify, Slack, Notion, Figma, Zoom, Microsoft Azure, **Apple**, X (Twitter), Kakao, KeyCloak. Все настраиваются одинаково: включить, вставить Client ID / Secret и добавить показанный Redirect URI в консоли разработчика этого провайдера (ссылка даётся для каждого).

То, что вы включаете здесь, — ровно то, что витрина читает через `client.auth.methods()`.

## Настройка URL

- **Site URL** — базовый адрес вашей витрины, по нему строятся ссылки в письмах и OAuth-редиректы (бэкенд их никогда не хардкодит).
- **Redirect URLs** — белый список разрешённых OAuth-callback адресов (поддерживаются маски вроде `https://*.yourdomain.com`). Это мера безопасности — завершить вход можно только по адресам из списка.

## Со стороны витрины

Сам вход идёт через SDK — см. [справочник по Авторизации](/docs/auth) про `sendCode`, `verifyCode`, `oauthLogin`, телефонный OTP, сессии и сброс пароля.

> В организации с несколькими филиалами и общими клиентами эти настройки провайдеров общие для всех филиалов.
