# Письма

**Проект → Письма** — здесь вы управляете почтой, которую отправляет магазин: и автоматическими письмами, и разовыми рассылками.

## Транзакционные шаблоны

Письма, которые магазин отправляет сам: подтверждение аккаунта, сброс пароля, подтверждение заказа, напоминание о записи, брошенная корзина, уведомление о поступлении и подобные. Для каждого можно:

- Редактировать содержимое в **визуальном редакторе** или в сыром **HTML**.
- Вставлять **переменные** вроде имени клиента или номера заказа — они подставляются для каждого получателя.
- Видеть **живой предпросмотр** и отправить себе **тест**.
- Задать тему и имя отправителя.

## Рассылки

Вкладка рассылок отправляет произвольное сообщение сегменту ваших [клиентов](/docs/customers-page) — анонсы, акции, новости.

## Доставка

Почта отправляется через собственный почтовый сервис Torta. Чтобы слать с вашего домена (и улучшить доставляемость), подтвердите его на странице [Авторизация](/docs/authentication) → Email — она проведёт вас по DNS-записям.
