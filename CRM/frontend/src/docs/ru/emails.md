# Письма

**Проект → Письма** — здесь вы управляете всей почтой, которую отправляет магазин: и автоматическими письмами, *и* разовыми рассылками. Страница устроена как ряд вкладок сверху: по одной вкладке на каждое автоматическое письмо плюс последняя вкладка **Рассылки**.

## Вкладки вкратце

Первые вкладки — это **транзакционные шаблоны**, письма, которые магазин отправляет сам, в ответ на действие клиента:

- **Подтверждение** — код при регистрации (одноразовый пароль).
- **Сброс пароля** — ссылка/код для восстановления.
- **Заказ** — подтверждение заказа после оформления.
- **Бронирование** — напоминание о записи.
- **Брошенная корзина** — напоминание, когда корзину оставили.
- **Поступление** — уведомление «снова в наличии» для товаров из листа ожидания.

Последняя вкладка, **Рассылки**, устроена иначе: это письма, которые отправляете *вы сами* — анонсы, акции, новости.

## Редактирование транзакционного шаблона

Все транзакционные вкладки работают одинаково. Вы получаете один редактор с живым предпросмотром под ним:

- **Тема** — тема письма. Тоже поддерживает переменные.
- **Вставить переменные** — нажмите на чип (например `{{customer_name}}`, `{{store_name}}`), чтобы вставить его в HTML. Каждый подставляется для своего получателя при отправке.
- **HTML** — пишите тело письма как HTML. Синтаксис подсвечивается; вёрстка полностью в ваших руках.
- **Медиа** (кнопка 🖼) — открывает вашу **Медиа-библиотеку**: загрузите фото и PDF, затем скопируйте ссылку и вставьте в HTML (`<img src="…">` для картинки, обычная ссылка для PDF). Библиотека общая для всех ваших писем и рассылок.
- **Живой предпросмотр** — превью в стиле Gmail обновляется по мере ввода, с подставленными тестовыми данными.
- **Отправить тест** — отправьте копию себе перед запуском.
- **Сбросить к настройкам по умолчанию** — вернуть исходное оформление Torta для этого письма.

> Некоторые шаблоны требуют определённую переменную. Например, «Подтверждение» обязано содержать `{{code}}` — редактор предупредит и не сохранит, пока вы её не вернёте. Изменения **сохраняются автоматически**.

## Рассылки

Вкладка **Рассылки** — это менеджер кампаний. В списке видны все кампании со столбцами **Название, Тема, Расписание, Отправлено** (скольким получателям дошло) и **Статус**. Список можно искать, переключать между видами **сетка и список** и через **меню ⋯** в каждой строке **изменить, приостановить/возобновить или удалить** кампанию.

**Статусы:** `черновик` (ещё не запланирована) → `запланировано` (ждёт своего времени) → `отправка` → `отправлено`. Приостановленная кампания показывает `приостановлено`; та, что упала с ошибкой — `ошибка`.

### Создание кампании

Нажмите **Новая рассылка**, чтобы открыть редактор. В верхней панели — **Назад** и редактируемое **название**. Ниже вы выбираете *когда и кому* с помощью переключателя из четырёх режимов:

- **Одному** — отправить на один email-адрес (удобно для быстрой проверки на живом человеке).
- **Всем** — отправить всем клиентам прямо сейчас.
- **Разовая** — выбрать **дату и время** для одной отправки. Галочка **Повторять ежегодно** делает её ежегодной (например, рождественская акция, которая повторяется каждый год в эту дату).
- **Еженедельно** — выбрать один или несколько **дней недели** и время; повторяется в эти дни.

Рядом с расписанием — **Исключить гостей**: оставьте включённым, чтобы пропустить клиентов из гостевого оформления и писать только зарегистрированным аккаунтам. Остальная часть редактора (тема, переменные, медиа, HTML, предпросмотр) полностью совпадает с редактором шаблонов выше.

Нажмите **Запланировать** (или **Отправить всем** / **Отправить** — в зависимости от режима), чтобы подтвердить. До этого ваши правки автоматически хранятся как черновик.

### Как работает время

- **Разовые** отправки срабатывают в выбранный момент по **вашему местному времени**.
- **Еженедельные** отправки используют **часовой пояс проекта** (задаётся в [Бронировании](/docs/booking-page) → Настройки), чтобы время оставалось одинаковым для ваших клиентов.
- Планировщик проверяет примерно **раз в минуту**, поэтому отправка происходит в пределах минуты от выбранного времени — не секунда-в-секунду.

### Кто получает рассылку

Все из вашего списка [клиентов](/docs/customers-page), у кого есть email и кто не отписался — все сразу, когда кампания срабатывает. Гости пропускаются, если включено **Исключить гостей**. В каждую рассылку автоматически добавляется **ссылка для отписки**, чтобы клиенты могли отказаться (после чего они исключаются из будущих отправок).

> Рассылки — платная функция, а количество писем в день зависит от вашего тарифа. Кампания, которая превысила бы дневной лимит, корректно останавливается, а не отправляется наполовину.

## Доставка

Вся почта идёт через собственный почтовый сервис Torta — никакой настройки для старта не нужно. Чтобы слать с **вашего собственного домена** (это солиднее и улучшает доставляемость), подтвердите его на странице [Авторизация](/docs/authentication) → Email; она проведёт вас по DNS-записям. После подтверждения **имя и адрес отправителя** будут использоваться во всех письмах этого проекта.
