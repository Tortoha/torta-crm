# Товары

**Проект → Товары** — самый большой раздел консоли: каталог плюс всё вокруг него — вариации, остатки, партии, цены, склады и категории. Это набор вкладок; эта страница проходит по каждой и по созданию товара.

Каждый товар — одного из трёх **типов**:

- **Физический** — есть вариации, остатки, склады, партии, доставка. Полная система.
- **Цифровой** — скачиваемый файл; без остатков и доставки.
- **Услуга** — бронируемая услуга, связана со страницей [Бронирование](/docs/booking-page).

Цены везде в валюте проекта (задаётся в [Настройках](/docs/settings)).

## Список товаров

Вкладка по умолчанию. Товары грузятся по 50 при прокрутке и сгруппированы **Физические → Цифровые → Услуги**.

**Панель инструментов:**

- **Поиск** — фильтр по названию по мере ввода.
- **Сортировка** — по имени, цене или дате; повторный клик меняет направление.
- **Фильтр по категории** — Все / Без категории / конкретная категория (категорию можно создать прямо тут).
- **Статус** — Все / Активные / На паузе.
- Переключатель вида **сетка / список**.
- **Импорт / Экспорт** — импорт товаров из CSV или экспорт каталога (или только выбранных строк) в CSV.
- **+ Новый товар** — название, опционально подзаголовок/описание, категория и тип.

**У каждого товара** видны обложка (клик показывает все фото), название, цена (одно значение или диапазон `$30–$45`), общий остаток, рейтинг и бейдж категории. Товары на паузе уходят вниз и открываются только из меню.

**Меню товара (⋮ или правый клик):**

| Действие | Что делает |
|----------|------------|
| **Редактировать** | открыть товар для настройки |
| **Дублировать** | клонировать весь товар |
| **Печать штрихкода** | открыть диалог печати (только физические) |
| **Пауза / Возобновить** | скрыть с витрины / показать |
| **Архивировать / Восстановить** | переместить в Архив (архивные — не продаются, но хранятся) |
| **Удалить** | удалить навсегда (с подтверждением) |

**Массовый режим** — выделите несколько товаров (правый клик → Выбрать), чтобы получить нижнюю панель: задать категорию, изменить цену на ±%, пауза/возобновить, архивировать, печать штрихкодов или удалить — всё разом.

### Импорт CSV

Перетащите `.csv` (колонки: `title` обязательна, плюс `subtitle, description, product_type, category, variation_name, configuration_name, sku_code, sku_barcode, price, stock_quantity`). Импорт сперва делает **пробный прогон** — сообщает, сколько товаров и SKU будет создано и какие ошибки по строкам, — затем вы **подтверждаете**, и импорт идёт по-настоящему.

### Печать штрихкодов

Отдельный диалог с живым предпросмотром печати. Вы выбираете, что кодировать (SKU товара, SKU конфигурации, партию, EAN-13…), **символику** (Code128, EAN-13, QR и другие), **формат этикетки** (термо 50×30 / 70×40 или листы A4), что показать на этикетке (название / SKU / цена) и число копий на строку. Дерево с чекбоксами позволяет напечатать ровно нужные товары/вариации/SKU. Каждому товару и SKU автоматически назначается корректный EAN-13, так что сканирование всегда работает.

## Создание товара

Откройте товар для настройки. **Всё сохраняется по мере ввода** (тост подтверждает), и большинство правок можно **отменить** из этого тоста.

### Многоуровневая конфигурация — ключевая идея

Это самое важное для понимания. У товара может быть **от 1 до 5 вложенных уровней конфигурации**, чтобы моделировать вариации ровно как они есть:

- **Уровень 1** — сетка карточек, например **цвета**. У каждой карточки есть галерея фото, имя и **Цена / Себестоимость / Вес**.
- **Уровни 2–5** — таблицы, вложенные под каждую карточку Уровня 1, например **размеры** под каждым цветом. Кликните карточку, чтобы провалиться в её строки. Самый глубокий уровень — это **лист** (реальный продаваемый **SKU**).
- Добавьте уровень глубже кнопкой **+ Создать уровень конфигурации**; нужно ровно столько уровней, сколько у товара вариаций (простой товар может остаться на одном Уровне 1).

**Наследование цены.** Цена ниже Уровня 1 необязательна — если оставить цену размера пустой, она **наследуется** от ближайшего родителя (плейсхолдер показывает, что подставится). Можно задать одну цену на цвет и дать всем размерам её наследовать, либо переопределить отдельные размеры. Так же работают и автоматические скидки (ниже).

**Остаток живёт на листе.** Остаток здесь не вводят — он добавляется *приёмкой инвентаря* (см. Инвентарь и Партии). Цвет или товар просто показывают **сумму** остатков своих детей.

**Копировать на соседние.** Собрали полный набор размеров для одного цвета? Один клик копирует эту структуру на все остальные цвета.

### Остальные блоки

В зависимости от типа товара на странице также есть:

- **Общее** — название, подзаголовок, описание, категория, тип.
- **Фото** — для каждой вариации: загрузка изображений / видео / 3D, перестановка (первое = обложка) или добавление по URL.
- **Модификаторы** (физические) — группы доплат вроде «доп. сыр / без лука»: чекбокс или радио, мин/макс, обязательность, с надбавкой к цене за вариант. Они проходят в корзину.
- **Характеристики** — пары ключ/значение, опционально по группам, привязанные к нужному уровню.
- **Кастомные поля** — ваши типизированные поля (текст, число, булево, дата, файл, JSON). Поле может быть **глобальным** (общим для всех товаров).
- **SEO** — SEO-заголовок, мета-описание, ключевые слова.
- **Детали услуги** (тип услуга) — длительность, вместимость, «требуется сотрудник», цена — связано с Бронированием.
- **Цифровые файлы** (тип цифровой) — файл(ы), которые приходят в письме с заказом.

### Вкладки страницы товара

| Вкладка | Что там |
|---------|---------|
| **Обзор** | всё вышеперечисленное — конфигурация и контент |
| **Настройки** | параметры товара и SKU: штрихкоды/бренд/HS-код, габариты, **запланированная цена распродажи (начало/конец)**, класс доставки и срок, дозаказ (backorder), предзаказ, B2B (MOQ, отсрочка, заказы по счёту), картинка для соцсетей |
| **История изменений** | только для чтения: **журнал остатков** (каждое изменение — кто, почему, какая партия) + **лист ожидания восполнения** (покупатели, попросившие уведомить) |
| **Отзывы** | отзывы с витрины об этом товаре (только чтение) |
| **API preview** | точный JSON, который публичное API отдаёт по этому товару — в помощь разработчику ([Каталог](/docs/catalog)) |

## Категории

**Плоский** список (без вложенности родитель/ребёнок). Создавайте категории, затем открывайте одну, чтобы переименовать и отметить, какие товары в неё входят. Удаление категории предлагает три режима: оставить товары (станут без категории), переместить их в другую категорию или удалить вместе с товарами (с подтверждением по имени).

## Инвентарь

Вид остатков для физических товаров — раскрываемое дерево **Склад → Товар → Вариация → SKU**. В каждой строке цена, себестоимость, прибыль и маржа (тонкая подсвечивается), плюс остаток и продано, которые суммируются от SKU.

- Фильтр **Все / Низкие / Нет в наличии** (низкие = 1–10 единиц).
- **Добавить остаток** открывает мастер приёмки; **Распределить** — мастер перемещения.
- **Редактировать SKU** — изменить остаток на +/- против выбранного склада и **партии**, с причиной (поставка, возврат, пересчёт, порча…) и заметкой.

Модель такая: **остаток ведётся по SKU, по складу, в партиях.** Любое число выше — это просто сумма.

---

## Партии

Принятый инвентарь ведётся **партиями** (лотами) — удобно для сроков годности, отзывов из продажи и учёта себестоимости. У каждой партии видно остаток к принято, даты производства/годности и статус (**Активна / Заморожена / Израсходована**).

- **Принять** партию: SKU, склад, количество, себестоимость единицы, опционально имя (иначе авто), даты производства и годности.
- **Заморозить** партию, чтобы её не продавали; **изменить** даты/заметки; **удалить** только пока она не тронута.
- **FIFO / LIFO** — настройка проекта решает, списываются ли продажи из самой старой партии (FIFO) или самой новой (LIFO).

## Цены: три разных инструмента

Их легко спутать, поэтому вот разница:

| Инструмент | Что это | Кто запускает |
|------------|---------|---------------|
| **Промокоды** | купон, который клиент **вводит на оформлении** | клиент |
| **Скидки** | **автоматическая цена распродажи** для всех | никто — она всегда включена |
| **Оптовые цены (Tier)** | **«бери N+, плати меньше за штуку»** | количество в корзине |

- **Промокоды** — процент или фикс-сумма, с мин. заказом, лимитами использования (общий + на пользователя), окном действия и опциональным ограничением по категориям.
- **Скидки** — задаются на товар, вариацию или один SKU как процент / сумма / фикс-цена, с опциональным расписанием. Скидки **наследуются вниз** по дереву уровней как и цены, а строка показывает цену до → после.
- **Оптовые цены** — лесенки по SKU (например, *10+ → $8 за штуку, 50+ → $6*) для B2B / опта.

## Склады

Задайте свои точки хранения. У каждого склада есть адрес, контакт и настройки **выдачи покупателю**: разрешить **самовывоз** (+ часы) и **срок доставки** (мин–макс дней), который питает подсказку «Доставка за 2–4 дня». Один склад — **по умолчанию** (новые SKU создают остаток там; его нельзя удалить).

Остаток здесь не редактируется — перемещение единиц между складами делается **мастером перемещения** (из Инвентаря).

## Настройки товаров

Общие для каталога значения и правила:

- **Массовые значения по умолчанию** — проставить значения (класс доставки, срок, порог низкого остатка, дозаказ, условия B2B…) сразу на **все** товары; перед применением показывается, что изменится.
- **Генерация SKU** — как формируются новые SKU (числовые / буквы / буквенно-цифровые / вручную + длина), с действием «перегенерировать все».
- **Группировка и именование партий** — как именуются авто-партии, и шаблон имени с токенами дат/последовательностей и живым предпросмотром.
