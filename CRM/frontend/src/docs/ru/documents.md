# Документы

**Проект → Документы** управляет внешним видом PDF, которые формирует магазин — счетов, чеков и подобных бумаг.

## Что можно делать

- **Выбрать шаблон** — стиль оформления (например, modern, classic, minimal) с живым предпросмотром.
- **Указать данные компании** — название, адрес, регистрационные / налоговые номера.
- **Брендировать** — загрузить логотип и выбрать акцентный цвет.
- **Задать подпись / футер** письма, который уходит вместе с документами.

Каждое поле сохраняется по мере изменения, с небольшим тостом-подтверждением — кнопки «Сохранить» нет.

Результат автоматически применяется к документам, которые получают клиенты (например, к счёту по заказу), так что ваши бумаги соответствуют бренду.
