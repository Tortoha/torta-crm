# Thesis by Turan College student Iskander Suleimenov, group PO 233, CRM system

This project involves not only a CRM system but also a clothing store, which work together. Each of these projects is written separately (Frontend and Backend), but they share a single database. This means that to run the entire project locally, you need to run five local hosts.

The frontend is written using React + Vite, and the backend is written using the FastAPI framework. The database used is MySQL.
