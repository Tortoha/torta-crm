## How to run a project locally

[Install Python](https://www.python.org/)
...\DIPLOM\Magaz\backend> .\venv\Scripts\activate
...\DIPLOM\Magaz\backend> pip install -r .\requirements.txt
...\DIPLOM\Magaz\backend> uvicorn main:app --reload
